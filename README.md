## 介紹

商城專案基於最新版本的[cool-admin-node](https://node.cool-admin.com/src/introduce/)、[cool-admin-vue](https://vue.cool-admin.com/src/introduce/)、[cool-uni](https://uni-docs.cool-js.com/src/introduce/)開發，外掛市場各式各樣的外掛都可以直接使用。

移動端是[cool-uni(基於 uni-app)](https://uni-docs.cool-js.com/src/introduce/)開發的，可以直接打包成 APP，小程式、H5 等跨端應用。

## 功能說明

完成了一個商城所需的流程閉環，如果你有其他特殊的業務需求，可以在此基礎上進行二次開發。

主要功能：

-   商品管理：商品列表、商品分類、商品規格、商品介紹、商品評價、購物車等
-   訂單管理：訂單列表、訂單詳情、訂單退款、發貨與物流查詢等
-   使用者管理：使用者列表、使用者詳情、使用者地址、隱私協議等
-   應用管理：意見反饋、投訴建議、版本升級
-   資訊管理：輪播圖、搜尋關鍵字
-   營銷管理：優惠券
-   客服系統：線上客服、客服訊息(可對接外掛市場的 AI 模組變成智慧客服)
