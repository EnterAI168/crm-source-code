## 介绍

商城项目基于最新版本的[cool-admin-node](https://node.cool-admin.com/src/introduce/)、[cool-admin-vue](https://vue.cool-admin.com/src/introduce/)、[cool-uni](https://uni-docs.cool-js.com/src/introduce/)开发，插件市场各式各样的插件都可以直接使用。

移动端是[cool-uni(基于 uni-app)](https://uni-docs.cool-js.com/src/introduce/)开发的，可以直接打包成 APP，小程序、H5 等跨端应用。

## 功能说明

完成了一个商城所需的流程闭环，如果你有其他特殊的业务需求，可以在此基础上进行二次开发。

主要功能：

-   商品管理：商品列表、商品分类、商品规格、商品介绍、商品评价、购物车等
-   订单管理：订单列表、订单详情、订单退款、发货与物流查询等
-   用户管理：用户列表、用户详情、用户地址、隐私协议等
-   应用管理：意见反馈、投诉建议、版本升级
-   信息管理：轮播图、搜索关键字
-   营销管理：优惠券
-   客服系统：在线客服、客服消息(可对接插件市场的 AI 模块变成智能客服)
