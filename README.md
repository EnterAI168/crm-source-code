# 台灣 CRM 管理系統

本專案是一套基於 **Cool-Admin** 深度客製的 CRM 管理系統，聚焦於 **客戶管理、報價單流程、發票審核、匯款管理、業績與獎金統計** 等實際營運場景，適用於業務、內勤、財務與管理者協同作業。

## 專案特色

- **客戶全生命週期管理**
  - 客戶列表、公池分配、VIP 標記、跟進記錄、郵件發送
- **報價單完整流程**
  - 新增、編輯、申請審核、優惠審批、部門審核、成本核算、發送報價、合約上傳
- **發票與財務流程**
  - 付款階段申請發票、財務審核、補發郵件、發票作廢、PDF 下載、匯款管理
- **業績與獎金管理**
  - 月度考核、年度考核、獎金統計、內勤統計
- **基礎資料維護**
  - 使用者、角色、部門、參數、字典、產品、供應商管理

## 角色說明

系統依角色顯示不同功能與資料範圍，常見角色包含：

- **系統管理員 / 老板**
  - 擁有高權限管理與審批能力
- **業務**
  - 維護客戶、建立報價單、送審、申請發票與折讓
- **內勤主管**
  - 依部門審核報價單並分配內勤
- **內勤**
  - 提交成本、處理分配到自己的案件
- **財務**
  - 處理發票審核、匯款管理、獎金統計

## 快速啟動

### 1. 啟動前端

```bash
cd cool-admin-vue
pnpm install
pnpm dev
```

預設啟動後可從瀏覽器開啟：

- `http://localhost:9000`

### 2. 啟動後端

```bash
cd cool-admin-midway
npm install
npm run dev
```

### 3. 打包前端

```bash
cd cool-admin-vue
pnpm run build
```

### 4. 打包後端

```bash
cd cool-admin-midway
npm run build
```

## 常見問題

### 1. 能進頁面但提示 API 沒有權限

請檢查：

- 角色是否配置對應按鈕權限
- 後端 `authority.ts` 是否已放行該 API

### 2. 報價單無法送審

請檢查：

- 報價單是否已儲存
- 明細與付款階段是否完整
- 優惠比例是否觸發老板審批

### 3. 財務頁面載入篩選條件報權限不足

通常是：

- 頁面權限已開
- 但查詢下拉 API 權限未映射到財務角色
