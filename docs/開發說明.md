# 開發說明

## 1. 專案概述

本專案是一個基於 Cool-Admin 深度客製化的內部 CRM 系統，涵蓋客戶管理、報價單、部門審核、發票、匯款、業績與獎金等業務情境。

技術棧：
- 前端：Vue 3、TypeScript、Vite、Element Plus、Pinia
- 後端：Node.js、TypeScript、MidwayJS、TypeORM、Cool-Admin Midway
- 資料庫：MySQL

目錄結構：
- `cool-admin-vue`：前端工程
- `cool-admin-midway`：後端工程
- `docs`：專案說明

## 2. 本地開發環境

環境要求：
- Node.js >= 18
- pnpm / npm
- MySQL 5.7+ 或 8.x

後端本機設定檔：
- `cool-admin-midway/src/config/config.local.ts`

目前預設設定：
- 資料庫類型：MySQL
- Host：`127.0.0.1`
- Port：`3308`
- Database：`cool-crm`
- Username：`root`
- Password：`root`

注意：
- `typeorm.synchronize = true` 僅適合本地開發，不建議在線上環境開啟。
- `cool.initDB = true`、`cool.initMenu = true` 會自動初始化部分資料庫與選單。

## 3. 啟動方式

### 3.1 前端啟動

```bash
cd cool-admin-vue
pnpm install
pnpm dev
```

預設訪問地址：
- `http://localhost:9000`

### 3.2 後端啟動

```bash
cd cool-admin-midway
npm install
npm run dev
```

### 3.3 打包

前端：

```bash
cd cool-admin-vue
pnpm run build
```

後端：

```bash
cd cool-admin-midway
npm run build
```

## 7. 開發建議

- 修改業務流程時，請同步檢查前端頁面、後端 service、SQL 遷移腳本與權限選單。
- 報價單、發票、匯款、業績模組之間存在高度業務關聯，變更時應一併驗證。
- 新增資料庫欄位時，優先補齊 entity、service、SQL 遷移腳本與說明。
