# 資料庫設計說明

## 1. 資料庫概覽

資料庫類型：MySQL

本專案圍繞 CRM 業務建構，核心資料物件包括：
- 客戶
- 報價單
- 報價明細
- 報價部門審核
- 報價付款階段
- 報價發票
- 匯款單
- 跟進記錄
- 業績與獎金配置

開發環境預設資料庫設定請見：
- `cool-admin-midway/src/config/config.local.ts`

## 2. 核心表關係

主要業務流程：
- `crm_customer_info` 1 --- n `crm_quote_order`
- `crm_quote_order` 1 --- n `crm_quote_order_item`
- `crm_quote_order` 1 --- n `crm_quote_order_stage`
- `crm_quote_order` 1 --- n `crm_quote_order_department_audit`
- `crm_quote_order_stage` 1 --- n `crm_quote_invoice`
- `crm_quote_order` 1 --- n `crm_quote_history`
- `crm_quote_order` 1 --- n `crm_remittance_stage`
- `crm_remittance` 可關聯 `crm_quote_order`

## 3. 核心表說明

### 3.1 `crm_customer_info`

用途：客戶主表

關鍵欄位：
- `id`：主鍵
- `companyName`：公司名稱
- `contactName`：聯絡人
- `mobile`：手機號碼
- `email`：信箱
- `industry`：行業字典值
- `isVip`：是否 VIP
- `isAdCustomer`：是否廣告投放客戶
- `status`：客戶狀態
- `salesmanId`：業務員 ID，為空表示在公池
- `dealCount`：累計成交次數
- `dealAmount`：累計成交金額
- `isDeleted`：邏輯刪除

索引重點：
- `contactName`
- `mobile`
- `salesmanId`

### 3.2 `crm_quote_order`

用途：報價單主表

關鍵欄位：
- `quoteNo`：報價單編號
- `customerId`：客戶 ID
- `quoteName`：專案名稱
- `quoteType`：專案性質，1 新案 / 2 續約
- `salesmanId`：業務員 ID
- `accompanySalesmanId`：陪同管理業務 ID
- `currentAssigneeId`：當前內勤處理人 ID
- `status`：主狀態
- `auditStatus`：審核狀態
- `assignStatus`：分配狀態
- `contractStatus`：合同狀態
- `invoiceStatus`：發票狀態
- `receiptStatus`：回款狀態
- `paymentStatus`：付款狀態
- `finalAmount`：總金額
- `costAmount`：總成本
- `grossProfitAmount`：毛利金額
- `grossProfitRate`：毛利率
- `discountRate`：優惠比例
- `discountDeductionAmount`：超額優惠扣獎金額
- `discountAuditStatus`：優惠審核狀態
- `sendType/sendEmail/sendTime`：報價傳送資訊
- `contractFile/contractFileName`：合同附件資訊
- `caseMeetingFlag`：是否召開案情會議
- `execRemark`：執行備註
- `projectStatus/projectStatusImages/projectCueSheet`：專案執行狀態補充欄位
- `allowanceApplyStatus`：折讓申請狀態
- `quoteTerms`：報價條款 JSON
- `remark`：備註
- `isDeleted`：邏輯刪除

索引重點：
- `quoteNo`
- `customerId`
- `salesmanId`
- `accompanySalesmanId`
- `currentAssigneeId`

狀態設計：
- `status`：主業務狀態
- `auditStatus`：整張報價單審核狀態
- `assignStatus`：整張報價單分配狀態
- `discountAuditStatus`：老闆優惠審核狀態

### 3.3 `crm_quote_order_item`

用途：報價單明細表

關鍵欄位：
- `quoteOrderId`：報價單 ID
- `productId`：產品 ID
- `departmentId`：產品所屬內勤部門 ID
- `specId`：規格 ID
- `productName/specName`：快照欄位
- `productType`：1 主力 / 2 一次性 / 3 附加
- `actualPrice`：實際報價
- `costPrice`：成本單價快照
- `quantity`：數量
- `subtotalAmount`：小計金額
- `subtotalCostAmount`：小計成本
- `grossProfitAmount`：小計毛利
- `costStatus/costUserId/costTime`：成本填寫資訊
- `remark`：備註
- `isDeleted`：邏輯刪除

索引重點：
- `quoteOrderId`
- `departmentId`

### 3.4 `crm_quote_order_department_audit`

用途：報價單按部門拆分後的審核、分配、成本填寫流程表

關鍵欄位：
- `quoteOrderId`：報價單 ID
- `departmentId`：內勤部門 ID
- `auditStatus`：1 待審核 / 2 通過 / 3 拒絕
- `auditUserId/auditTime/auditRemark`：審核資訊
- `assignStatus`：0 未分配 / 1 待分配 / 2 已分配
- `assigneeId`：被分配內勤 ID
- `assignUserId/assignTime/assignRemark`：分配資訊
- `costStatus`：0 未填寫 / 1 已填寫
- `costUserId/costTime`：成本填寫資訊
- `isDeleted`：邏輯刪除

索引重點：
- `quoteOrderId`
- `departmentId`

來源腳本：
- `cool-admin-midway/src/modules/customer/sql/add_quote_department_audit.sql`

### 3.5 `crm_quote_invoice`

用途：報價單付款階段發票表

關鍵欄位：
- `invoiceNo`：發票編號
- `quoteOrderId`：報價單 ID
- `quoteStageId`：付款階段 ID
- `quoteNo/quoteName`：報價資訊快照
- `stageNo/stageName/ratio/amount`：付款階段資訊
- `invoiceProductName`：開票產品名
- `seller/address/taxNumber/email`：開票主體資訊
- `applyUserId/applyTime`：申請資訊
- `status`：發票審核狀態
- `auditUserId/auditTime/auditRemark`：發票審核資訊
- `ecpayInvoiceNo/ecpayInvoiceDate/ecpayRandomNumber`：綠界發票回傳資訊
- `ecpayIssueStatus/ecpayIssueError/ecpayIssueTime`：綠界開票狀態
- `ecpayInvalidStatus/ecpayInvalidReason/ecpayInvalidTime`：綠界作廢狀態
- `autoSendEmail/scheduledSendTime/sendStatus/sentTime/sendError`：郵件傳送狀態
- `voidTime`：作廢時間
- `isDeleted`：邏輯刪除

索引重點：
- `invoiceNo`
- `quoteOrderId`
- `quoteStageId`

### 3.6 `crm_remittance`

用途：匯款單主表

關鍵欄位：
- `remittanceNo`：匯款單編號
- `remittanceName`：匯款專案名稱
- `quoteOrderId`：關聯報價單 ID
- `remittanceType`：匯款類型
- `supplierId`：供應商 ID
- `supplierCompanyName`：供應商公司名快照
- `accountInfo`：帳號資訊
- `totalAmount`：匯款總額
- `paidAmount`：已匯款金額
- `status`：1 匯款中 / 2 已完成
- `salesmanId`：業務員 ID
- `uploadFiles`：附件
- `invoiceFiles`：發票附件
- `receivedLaborInsurance`：是否收到勞保單
- `receivedInvoice`：是否收到發票
- `remark`：備註
- `isDeleted`：邏輯刪除

索引重點：
- `remittanceNo`
- `quoteOrderId`
- `supplierId`
- `status`
- `salesmanId`

## 4. 典型狀態流

### 4.1 報價單主流程

- 新建報價單
- 提交審核
- 整單審核 / 優惠審核
- 部門審核
- 部門分配
- 成本填寫
- 報價傳送
- 合同上傳
- 發票 / 回款 / 匯款 / 業績聯動

### 4.2 部門審核流程

基於 `crm_quote_order_department_audit`：
- `auditStatus = 1`：待部門審核
- `auditStatus = 2`：部門審核通過
- `assignStatus = 1`：待分配內勤
- `assignStatus = 2`：已分配
- `costStatus = 1`：已提交成本
